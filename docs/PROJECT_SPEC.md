# AutoCut — 프리미어 프로용 AI 러프컷 & 레퍼런스 분석 도구

## 목표
1. **모듈 B (자동 러프컷)**: 촬영 소스 폴더를 넣으면 대사·장면을 분석해 러프컷을 만들고, 프리미어 프로에서 바로 열리는 XML로 내보낸다.
2. **모듈 A (레퍼런스 분석기)**: 완성된 영화/영상을 분석해 편집 스타일 프로필과 장면 라이브러리를 만들고, 모듈 B가 이를 편집 기준으로 쓴다.

결과물은 "완성본"이 아니라 사람이 다듬을 **70~80% 수준의 러프컷**이 목표다.

## 전제
- 실행 환경: 영상과 프리미어 프로가 있는 사용자 로컬 컴퓨터
- 언어: Python 3.11+
- 프리미어 연동: FCP7 XML(xmeml) 내보내기 → 프리미어에서 Import. (UXP 패널 플러그인은 나중 단계)
- 소스 종류: 대사 위주(인터뷰·토크)와 대본 있는 촬영본(단편·드라마) 둘 다 지원. 대본 파일이 주어지면 대본 매칭 모드로 동작.
- 원본 영상은 절대 수정·복사하지 않는다. 분석 데이터만 저장한다.

## 파이프라인 (모듈 B)
1. **수집**: 소스 폴더 스캔, ffprobe로 길이·fps·타임코드·오디오 채널 메타데이터 수집
2. **음성인식**: WhisperX(또는 faster-whisper + 정렬)로 단어 단위 타임코드 + 화자 분리. 한국어 기본.
3. **샷 분석**: PySceneDetect로 샷 경계 감지 → 샷마다 대표 프레임 1~3장 추출 → 비전 모델로 샷 크기(CU/MS/WS), 인물, 내용 설명
4. **오디오 신호**: 무음 구간, 음량, 웃음·톤 상승 구간 감지
5. **테이크 점수**: 같은/비슷한 대사가 반복되면 필러("어", "음") 빈도, 말더듬, 오디오 품질, 얼굴 노출로 점수 매겨 베스트 테이크 선택. 대본이 있으면 대본 줄 ↔ 테이크 정렬.
6. **LLM 다단계 편집 판단** (Claude API)
   - 1단계: 전체 대사 + 샷 설명으로 이야기 뼈대(주제, 핵심 포인트, 흐름) 작성
   - 2단계: 뼈대 각 부분에 들어갈 구간 선택 (스타일 프로필 반영)
   - 3단계: 처음 보는 시청자 관점으로 컷 리스트 검토 → 맥락 단절, 중복, 미설명 언급 수정
   - 각 컷에 "선택 이유"를 함께 출력
7. **컷 지점 보정**
   - 컷을 단어 경계 근처 무음 구간에 스냅
   - 앞뒤 핸들(기본 4~6프레임), 오디오 짧은 크로스페이드
   - 문장 중간 컷 자동 검사·차단
8. **내보내기**: FCP7 XML 생성. 원본 파일 경로 연결 유지, 각 컷에 선택 이유를 마커 코멘트로 삽입, 제외 후보 구간은 별도 색 마커로 표시.

## 파이프라인 (모듈 A)
1. 샷 경계 감지 → 장면 묶기
2. 지표 추출
   - 장면별 평균 샷 길이, 전체 템포 곡선
   - 샷 크기 분포와 대화 장면의 샷 크기 전개 패턴
   - 대사-컷 관계: 리액션 샷 비율, J컷/L컷 비율(대사 경계와 컷 지점 비교)
   - 전환 종류(컷/디졸브/페이드), 음악 진입·이탈, 무음 사용
3. **스타일 프로필**(JSON + 사람이 읽는 요약) 저장 → 모듈 B 2단계에 규칙·예시로 주입
4. **장면 라이브러리**: 장면 설명·지표를 로컬 DB(SQLite)에 저장, 자연어 검색("긴장이 올라가는 대화 장면") 지원, 검색 결과를 XML로 내보내 타임라인에서 구조 확인 가능

## 스타일 학습 루프
- AI 러프컷 XML과 사용자가 다듬은 최종 XML을 비교해 차이를 요약 → 개인 스타일 가이드에 누적 → 다음 편집에 반영

## 비용·성능 원칙
- 비전 모델에는 샷당 대표 프레임만 보낸다 (전 프레임 금지)
- 모든 분석 결과는 캐시해서 재실행 시 재사용
- 장편은 장면 단위로 나눠 처리, 진행률 표시, 중단 후 이어하기

## 폴더 구조 (제안)
```
autocut/
  cli.py              # autocut analyze / cut / reference / learn
  ingest/             # 메타데이터, 프레임 추출
  transcribe/         # WhisperX, 화자 분리
  shots/              # 장면 감지, 비전 태깅
  audio/              # 무음·음량·신호
  takes/              # 테이크 점수, 대본 매칭
  edit/               # LLM 다단계 판단, 컷 보정
  reference/          # 모듈 A 지표, 스타일 프로필, 라이브러리
  export/             # FCP7 XML, 마커
  cache/
tests/
  fixtures/           # 짧은 테스트 클립
```

## 개발 순서
1. 수집 + 음성인식 + 단순 XML 내보내기 (전체 대사 구간만 이어붙이기) → **프리미어에서 열리는지 먼저 확인**
2. 무음 스냅·핸들·크로스페이드 등 컷 보정
3. LLM 다단계 편집 + 마커
4. 샷 분석 + 테이크 점수 + 대본 매칭
5. 모듈 A 레퍼런스 분석기 + 스타일 프로필 연결
6. 스타일 학습 루프
7. (선택) B롤 자동 배치, 멀티캠 앵글 전환, UXP 패널

## 시작 전 확인할 것
- OS(맥/윈도우), GPU 유무 → 음성인식 로컬/API 결정
- Anthropic API 키 환경변수 설정
- 프리미어 프로 버전, 테스트용 짧은 클립 2~3개
